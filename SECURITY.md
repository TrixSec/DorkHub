# Security Policy

## Supported Versions

DorkHub is a repository of Google Dorks and does not have versions in the traditional software sense. We strive to keep the dorks relevant and updated.

## Reporting a Vulnerability

If you find a security issue within the structure of this repository (e.g., malicious links injected into dork files, CI/CD pipeline vulnerabilities, etc.), please report it.

### How to Report

Please do not open a public issue for security vulnerabilities. Instead, please contact the maintainer directly at [insert contact method, e.g., Telegram @Trixsec].

We will acknowledge receipt of your vulnerability report and work to address it promptly.
