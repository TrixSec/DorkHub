# API Dorks

This category contains dorks tailored for discovering exposed Application Programming Interfaces (APIs), including:
- REST APIs (Swagger/OpenAPI UI)
- GraphQL endpoints (GraphiQL, GraphQL Playground)
- Exposed API keys and secrets in logs or configuration files

**Risk Level:** High
Exposed APIs often lead directly to sensitive data access or unauthorized actions.

**Usage:**
Run these dorks on Google or GitHub to find inadvertently exposed API endpoints or hardcoded keys.
